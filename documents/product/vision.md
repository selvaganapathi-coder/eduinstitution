# Product Vision

## Product

EduInstitution is a production-grade education management system designed initially for pharmacy colleges and structured so it can evolve into a broader education management SaaS platform.

## Primary Goal

Provide simple, reliable, familiar software for college administration, faculty, and students while maintaining strong security, data integrity, maintainability, and scalability.

## Product Principles

- Simple for users.
- Structured for developers.
- Mobile-first.
- Familiar enterprise workflows.
- Strong server-side security.
- Incremental vertical-slice development.
- No unnecessary architecture or UI trends.

## Initial Technology Direction

- Next.js
- React
- TypeScript
- Ant Design
- Prisma
- Neon PostgreSQL
- Cloudflare Workers/OpenNext
- Cloudflare R2
- GitHub

The exact versions and runtime compatibility are recorded in architecture decision records and must be verified against the actual repository before implementation.
