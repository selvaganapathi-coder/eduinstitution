## Institution-Type Roadmap

The platform is designed to support multiple institution categories through configuration and module extensions:

- School
- Engineering College
- Pharmacy College
- Arts & Science College
- University
- Polytechnic
- Training / Vocational Institute
- Other education institutions

New modules must document which categories they support before implementation.

## Planning Rule

No substantial feature may move directly from an idea to implementation. The task must first document:

- fields and data lifecycle
- routes and navigation
- complete user flow
- access/permission matrix
- institution-type compatibility
- API/server flow
- database impact
- UI/content specification
- mobile-responsive behavior
- security
- testing
- CI/CD
- documentation
- definition of done
